# SuccessWikis landing page

A responsive Next.js App Router recreation of the supplied SuccessWikis Framer reference, built with TypeScript, custom CSS, GSAP and ScrollTrigger.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm start
```

## Motion implemented

- Scaled hero/title entrance with staggered metadata and CTA reveal
- Scroll-scrubbed manifesto word highlighting
- Scroll-triggered section heading, copy and card entrances
- Subtle image parallax in editorial photo panels
- Button lift/color and feature-card inversion hover states
- Full `prefers-reduced-motion` fallback

See `ASSET_MAPPING.md` for the image audit and `verification/` for desktop/mobile comparison captures.
