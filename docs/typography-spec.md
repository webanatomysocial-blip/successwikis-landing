# Typography specification

| Role | Family | Weight | Desktop size | Mobile size | Treatment |
|---|---|---:|---:|---:|---|
| Home hero | Inter | 700–800 | fluid up to 171 px | 31–47 px | uppercase, -2% to -6.5% tracking |
| Contact/FAQ display | Anton | 400 | 55 px | 40 px | condensed uppercase |
| Section display | Inter | 700–800 | 48–170 px | 40–67 px | tight tracking |
| Body | Geist / Inter | 400–500 | 14–20 px | 14–16 px | -3% where published |
| Labels/countdown captions | Martian Mono | 400–600 | 10–12 px | 7–11 px | uppercase, wide tracking |
| Buttons | Inter / Martian Mono | 600 | 13–16 px | 12–14 px | reference-specific |

The published reference exposes Anton, Geist, Inter and Martian Mono resources. This implementation uses their licensed Google-hosted equivalents; minute rasterization differences from Framer's asset-hosted builds may remain.
